# 录题审核页面加载优化

2026-11-05定位：页面在显示任何题卡前，先逐题扫描12553道正式题统计查重信息；每对比较重复归一化题干、选项和生成双字集合。Streamlit缓存依赖整个SQLite/WAL文件变化，且只有256条容量，草稿编辑或进程重启后容易重新计算。任务树另有反复遍历2569个节点的成本。

已调整：

- 相似度算法复用有界缓存中的归一化特征、精确文本签名及不可变双字集合，规则和阈值不变。
- 正式题快照按SQLite及WAL文件状态刷新，按正式题ID、题干、选项和题型的完整有序内容计算指纹。独立data/cache/question_matches_*.sqlite3持久保存查询结果；缓存键包含内容指纹、评分代码版本、输入、阈值及结果数量。正式题增删改会失效，单纯草稿编辑可复用。源数据库只读，缓存损坏或不可写时回退实时计算。
- 题卡先显示，再逐题计算提示；整卷统计随后更新，不再在首题前等待整卷查重。所有题仍全部展开。
- 任务目录使用父子索引遍历及直接计数索引，避免反复扫描整个目录。

本机同一2025清华7题试卷：原查重路径13.7569秒，优化首次3.2849秒，缓存命中0.0053秒。真实工具箱路由AppTest（含题文、解析、配图渲染调用）首次1.1357秒，再运行0.2059秒；此为本机服务端测试耗时，不含用户浏览器网络和绘制。任务树读取约0.0938秒。

验证命令：

```powershell
python -m unittest tests.test_question_match_cache tests.test_question_similarity_review
python scripts/smoke_ingestion_review_ui.py
python scripts/benchmark_ingestion_review_matches.py
```

最后一个命令在只读正式题库上核对本批416题与先前查重报告的结果一致，并预热可丢弃缓存；报告写入data/imports/qj_2021_2025/review_performance.json。独立缓存无需备份，删除后可重建；新增或修改正式题后的首次计算仍需一定时间。

## 全局浏览及所有审核任务的共用优化

同日后续更新：优化入口覆盖所有任务，不按QJ批次或年份限定。审核页仅加载选中试卷的题文及配图，资源通过一次联表读取，取消逐题重复打开连接；当前年份及整个任务的批量按钮使用任务树计数，点击后才读取相应范围题文。

全局浏览、检索及其他SQLite消费入口共用read_cache_service中的有界只读缓存：筛选项128项、分页128项、详情256项。缓存键包含绝对数据库路径、SQLite及WAL文件纳秒时间和大小、查询参数。返回深拷贝，避免表单修改污染缓存；显式事务连接绕过缓存。数据库写入后自动失效。预览层也改用包含WAL的token，避免未checkpoint时显示旧内容。

本机实测共用查询首次/复用：筛选项约0.07028/0.00014秒，分页0.00688/0.00037秒，详情0.02860/0.00007秒。全局浏览10题真实路由AppTest首次约1.2372秒、再次0.0974秒；包含服务端题文和预览渲染调用，不含浏览器绘制。

审核页不再展示PDF证据的重复说明及通用转写备注，有实质内容的来源疑点继续显示。底层来源证据、原始备注未删除。按钮使用同一CSS网格行显示“✅ 确认本题审核通过”和“❌ 本题放弃录入”；选择器同时兼容旧版element-container与新版stElementContainer，并覆盖组件的内联固定宽度。当前Streamlit不支持三层columns或container(key=...)，因此使用原生按钮配合网格。

浏览器在1440及430像素宽度均验证按钮同行、不重叠、无横向溢出及重复文案消失，全局浏览10题正常加载。截图和几何报告在data/reports/review_actions，脚本scripts/check_review_actions_layout.cjs使用本地临时核验服务8517。服务应在核验后关闭。单元测试覆盖WAL未checkpoint更新、缓存失效及可变返回值隔离。
