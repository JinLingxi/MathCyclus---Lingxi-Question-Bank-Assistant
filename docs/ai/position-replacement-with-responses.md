# 同位置冲突按可信草稿覆盖与旧答案保全

用户确认 651 道草稿题干与来源正确，授权覆盖对应题位的旧正式题。旧题答案解析先搜索本轮 8,516 条任务草稿，并对其中可确认的匹配作迁移，再覆盖。此次不处理另 514 道内容重复跳过草稿。

## 逐题检查与答案归属

651 道旧题中，482 道答案与解析均为空，169 道至少有一项。全部保存逐题原始快照并对照：

- 66 道通过严格题干、数字、题型和选项匹配，对应原题位。
- 22 道严格匹配到本轮其他草稿。
- 对其余候选人工逐项阅读文本差异后，43 道确认是原题位的等价表述或类型标注差异，7 道确认对应其他草稿。
- 剩余 31 道存在条件变动、不同题目、选项换序/不同、原解不对应或无可靠匹配，不直接套用答案。全部保存成独立的“旧答案解析待核对”草稿，包括原题干、选项、答案、解析和旧图片引用，保持 needs_review，不自动入库。

原 169 道的 307 个非空答案/解析字段逐项验证：或者出现在匹配目标草稿，或者原样出现在独立保全草稿。已有不同答案解析时禁止无提示覆盖，保留冲突旧版；本轮预演未遇到额外字段覆盖冲突。

选择题选项换序时不能直接复制答案字母，解析中的选项编号也可能变化；这类记录未可靠解决前进入保全草稿，而不是机械替换字母。解析为旧数据迁移，不等于完成所有数学推导正确性的复核。

## 覆盖方式与保护

保留 651 个正式 question_id 和来源题位，通过既有事务内草稿提交服务更新正文。每条先校验草稿、绑定内容哈希和本次用户批量确认，再提交 update，记录审核与修订事件。

新图片按新草稿资源重新登记，使用独立版本目录，避免旧图文件同名占位或旧别名优先匹配。旧图片文件原地保留，旧登记完整写入执行报告和数据库备份；回退不依赖覆盖后的路径猜测。

知识板块按可信新草稿重建，原分类保存在清单/备份。受内容改变影响的已批准同题关系转为 pending 并追加事件，关系本身不删除；无关题目不改。全体旧 question_analysis 字段预查为空，没有丢失扩展解析。

已录入的其他目标题若接收答案/解析，只更新这些字段和 canonical_tex；题干、选项等保持不变。已经 committed 的原草稿同步保存答案，并记录迁移事件，不把原题内容偷偷改掉。

## 演练、实际清单与验证

只读匹配计划 reports/position_replacement_plan_20261103.json，人工核对后的计划 reports/position_replacement_reviewed_20261103.json。每个候选含评分、数字/题型/选项检查、前五候选和明确检查理由。

scripts/apply_position_replacement.py 默认复制真实数据库到隔离目录演练，用临时图片目录实际复制验证。加 --apply 时先用 SQLite backup API 备份，再以单一事务覆盖全部题目、迁移答案并创建保全草稿；任何校验失败则回滚数据库。实际结果为 reports/position_replacement_applied_20261103.json，其中 backup 和 asset_root 记录恢复依据。

scripts/review_position_answer_routes.py 中逐条记录已人工读取差异的额外归属决策，不通过降低全局相似阈值强行匹配。无法可靠归属仍保持未决。

覆盖验证包括范围外正式题逐字段未变、651 道新正文/选项与可信草稿一致、原非空答案解析不丢失、正式题总量不变和数据库完整性。后续追加正式资源引用/哈希检查与审核页回归。
