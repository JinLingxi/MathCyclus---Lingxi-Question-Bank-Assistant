# 五组真题任务按“录入本批非重复题目”录入

用户明确要求把录题任务审核中的待审核题，按现有“录入本批非重复题目”按钮规则录入。范围为五组 codex_task 的试卷子树，共 8,516 条草稿，其中 8,431 条待审核、85 条此前已入库。

## 执行口径

保持现有按钮语义：同卷同题号已有题目时跳过；内容判定为 exact 时跳过；similar 候选不排除。校验错误或提醒仍阻止录入。每题通过现有 approve_draft_for_commit、commit_draft_to_question 服务录入，不直接拼写正式题表，不关闭外键或审核门槛。

本次明确用户批量指令作为批量确认，操作人记录为 user_requested_non_duplicate，不伪装成用户曾逐题查看。既有来源疑点备注保留在原草稿，批量入库不代表这些疑点已消失。答案和解析缺失允许保留，不猜测补写。

完全重复筛选复用 score_question_pair，仅对 stem_norm 相同的候选调用原判定器；完全重复必须满足此条件，因此省去相似排名不改变该模式的排除集合。批内每录入一题立即加入查重集合，后续题目按实时库检查。

## 预演与恢复材料

副本演练报告：reports/nonduplicate_rehearsal_fixed_20261103.json；逐项日志为同名 .journal.jsonl。预演新增 7,266 道、跳过 exact 514 道、位置冲突 651 道、已有入库 85 道，未发生录入失败。

执行前使用 SQLite backup API 保存一致性备份，路径写入 reports/nonduplicate_applied_20261103.json 的 backup 字段。逐题日志 reports/nonduplicate_applied_20261103.journal.jsonl 即时落盘，保存草稿 ID、处理结果和正式题 ID；程序中断可依据 committed 状态继续，不重入已入库草稿。

本次修复一个预演发现的后端错误：标准试卷的 paper_id 为空时，之前 str(None) 会得到字符串 None 并触发外键失败；现在空值走正常建卷关联流程。新增独立回归测试覆盖这个场景。

本次不删除重复/冲突草稿，不自动合并题目、不归零历史来源疑点，不改 UI 或默认导出模板。剩余重复候选后续可逐项确认是否仅需建立来源关联，不能直接删除。
