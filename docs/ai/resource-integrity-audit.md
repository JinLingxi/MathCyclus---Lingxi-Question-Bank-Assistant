# 资源引用完整性检查

后续整理可使用带 --baseline 的统一入口进行检查和前后逐项对比，避免只比较问题数量。规则与退出码见 [resource-acceptance.md](resource-acceptance.md)。

## 工具

运行项目虚拟环境 Python 模块 scripts.audit_resource_integrity，并用 --output 指定新的 JSON 报告路径。这是只读审计；会检查正式题、草稿、资源文件哈希、TeX 图片占位、PDF 导入任务、来源 PDF 哈希，以及任务 JSON 中引用的原页和裁剪文件。绝对外部路径不写入报告，仅显示“external path”。

该检查只报告，不自动换图、修路径、修改题意、重置审核状态或删除文件。无引用文件不能由此推断为可删除。

## 深度可读性检查

添加 --check-readability 可额外检查草稿 extra_json 中的来源 PDF、来源页码、整题截图与原页图片，以及登记资源和任务页面的实际解码。图片使用 Pillow verify 和 load；PDF 使用 PyMuPDF 打开并核对页数，不执行文件内脚本，也不重编码。相同路径缓存结果以避免反复打开合订本。

页面路径优先根据明确记录的 document_job_id 解析；不能解析的记录会报告待核对，不会猜测另一个题目或任务来补齐。可读只表示格式解码通过，不代表配图归属、标签清晰度或题意已人工复核。SVG、视频等非位图格式不在图片解码覆盖范围；多帧图像仅校验格式和默认帧，不能据此声明所有帧已验证。

本轮深度扫描报告为 reports/resource_readability_audit_20261103.json：检查 2,283 条可找到文件的登记资源、8,526 条草稿来源/截图引用、9,555 个来源页码和 28,240 条任务原页图片记录；去除同路径重复探测后，共 30,526 张图片成功解码、1 份来源合订本成功打开。未发现新增缺图、解码失败或来源页码越界，仍只有示例图片缺失和 created 任务载荷待生成两条已知状态。63 项回归测试通过。

## 2026-11-03 结果

审计检查 1,056 道正式题、8,524 条草稿、2,259 条草稿资源，以及 88 个 PDF 任务和 45,240 条任务资源路径引用。所有任务 PDF 都存在且与来源清单哈希一致，所有解析到的页图、裁剪图和资源引用都存在。

正式资源、题干/选项/答案/解析中的图片引用及正式资源哈希均无异常。旧 2016 浙江卷图像记录用 16 位 SHA-1 截断值；校验已兼容 16 位旧 SHA-1、完整 SHA-1 和 64 位 SHA-256，未修改图片或数据库。
