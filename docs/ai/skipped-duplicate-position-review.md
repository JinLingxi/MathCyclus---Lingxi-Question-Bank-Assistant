## 两组含义

651 道 position_conflict 在查重前因来源题位已被占用而跳过；514 道 exact_duplicate 没有该来源位置冲突，但与已入库的其他位置题目内容完全重复。两组草稿 ID 不重叠，514 并非包含在 651 中。核对时每组原匹配 ID 均已复查，514 道原匹配正式题中没有同题位关联；651 道全部仍有对应同题位正式题。

514 道中，513 道题干、选项与图片字节一致；1 道仅存在有限排版归一化差异。此结论不表示同一题可以丢弃另一个来源，来源关系仍需单独保留与审核。
