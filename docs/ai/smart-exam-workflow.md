# SQLite 智能组卷：候选池与试题篮

## 当前流程

点击组卷页的“智能组卷”，按顺序设置条件、生成候选池、查看可用数量及候选题、生成初选方案，最后确认放入试题篮。生成候选池和初选方案均不修改正式题库或原题文件。

常用界面显示板块、难度偏好、目标题数及当前筛选，题数与页面上方同步；指定题型数量时改用配额合计。无手选题时不展示试题篮处理选项。补充想法、AI 润色以及高级参数默认折叠。难度偏好提供不限、基础、适中、提升和自定义范围，实际范围会同步应用；未标注难度策略、候选规模和可复现抽题编号仍可在高级设置中调整。“换一批候选”沿用当前条件，更新抽题编号并重新生成候选池，不改动试题篮。

- 默认继承左侧关键词、年份、来源类型、卷别、试卷来源、板块、题型和难度条件；可以关闭继承。界面显示实际继承条件。
- 板块来自现有知识板块表，包含新增板块；可按主板块或全部关联板块匹配。“高考范围”沿用既有预设范围。
- 全库先筛选，再做保守的同题去重和候选预算分配。预算不是数据库前 N 条；指定题型数量时，预算优先预留对应配额。
- 使用正式题型 code 区分单选、多选、填空、解答和其他，不以答案字母猜测题型。
- 未标注难度保持未知。已标注题须在范围内；是否允许未知及整套未知题上限由用户指定。目标星级是排序偏好，不声称精确满足整卷平均难度。
- 意图文字用于本地关键词排序。AI 润色需用户主动点击，建议可核对后采用；它不自动改写硬筛选条件，不生成题目。
- 同一个抽题种子及同一数据快照可复现结果。换种子可换同优先级题目。

## 缺口与手选题

试卷模板默认提供 8 单选、3 多选、3 填空、5 解答的可编辑配额。练习模板默认使用上方目标题量，题型数量可另行指定；指定配额后，以配额总数为本次目标，首版单次最多 200 题。

默认“补足当前试题篮”：保留手选题及顺序，按剩余题量或题型配额补充。范围外手选题作为锁定题保留，但须确认提示。超过目标题量、某题型手选数超额、未知难度超限或候选不足时，显示明确原因并禁止确认，不自动放宽或用其他题型代替。

“重新生成整套”会清空原选题，已有手选题时需勾选明确替换确认。初选方案绑定当前条件、手选题和排除项；变化后需重新生成。确认时再次检查选中题目的内容/分类/资源登记及已批准同题关系，已变化的方案不能直接放入。

去重依据为题目 ID、题干/选项/题型和登记图片身份均一致的保守完全相同判断，以及已批准的 same_question/same_stem/duplicate/exact 关系。变式和其他关系不自动合并。初选提示已有其他关系、同题干但选项或图片不同的情况；首版未对所有候选两两重算相似度，也未引入向量检索或数学等价证明。

## ID 选题与导出

SQLite 题目在现有会话试题篮中使用 sqlite: 加 question_id，不依赖旧 TeX 是否存在。可明确关联的历史桥接路径转换为 ID，同时保留手排结构；无法关联的旧文件须先核对，不能伪装成正式题。

试题篮直接读取 SQLite 预览。进入排版时，按题目内容与资源登记生成 data/cache/exam_typesetting/ 兼容副本；该缓存已被 Git 忽略，可重建。正式导出时将题目和图片放进对应导出目录，并将组合 TeX 中的资源路径改为导出目录内相对路径。缺资源会报错，不默默丢题。

SQLite 试卷格式化根据正式题型选择环境，避免仅凭“第4节”认定为解答题。旧 TeX 路线沿用原规则。标准 8/3/3/5 顺序保留原有解答题 13、15、15、17、17 分规则；自定义题量或顺序时 SQLite 解答题兼容环境默认 12 分。首版不优化整卷分值，章节说明及总分仍需在排版台/导出结果中核验，不把题型配额等同于完整命题规范。

新生成试卷的引用次数沿用生成后计数机制；SQLite 计数通过服务层执行，先保存一致性备份，仅更新 usage_count。覆盖同名试卷按原 UI 规则不重复增加。候选池生成、篮子确认和进入排版都不增加计数。

## 验证

- python -m unittest tests.test_smart_exam_service -v：全库先筛、正式题型、未知难度、配额、手选题、重复与图片区分、方案过期、无旧文件的资源物化、旧文件兼容、引用计数及导出环境。
- python scripts/smoke_exam_selection_service.py：当前工作库只读候选及配额检查。
- python scripts/smoke_legacy_exam_selection_service.py：旧 CSV/TeX 选题兼容检查。
- node scripts/check_smart_exam_flow.cjs：手选保留、候选→初选→确认→进入排版、返回选题和不足阻止确认；不点击最终导出，不调用 AI。

测试写入只使用临时库和临时目录。实际工作库只进行只读查询；浏览器验证只更新会话状态与排版缓存，不修改题干、选项、题型或审核状态。局部检查不替代发布前完整回归和所有模板的实际 PDF 编译验收。
