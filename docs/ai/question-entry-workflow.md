# 题目录入与 AI 识别流程

数学纠错边界（用户明确要求）：只允许修订答案、解答和解析，不得为了使原题成立而改动题干、选项或题型，不得添条件、删条件或替换干扰项。原题本身条件矛盾、缺条件或无正确选项时，在答案和解析中如实说明，保留原题。依据原页纠正OCR误识别或转写错误属于还原原文，应与修改原题区分。2025—2021清北强基本批曾有34题被越界改动，现已撤回，后续重建必须通过原题字段不变校验。

归档前格式补充：指定填空横线后的中文句号统一改为英文句点，不批量替换正文中文句号。录入审核任务的来源疑点备注必须逐题人工核对；格式校验与公式可渲染不等于原文无误。

草稿图片现保存到稳定的 data/draft_assets 资源目录，避免审核预览依赖临时录题文件。规则、历史迁移和回退工具见 [draft-asset-storage.md](draft-asset-storage.md)。该目录不是缓存，清理任务文件时必须保留。

补充：相似题差异提示、选项图片校验、来源裁剪复核协议和 Word 公式提取的当前边界见 [external-project-improvements.md](external-project-improvements.md)。这些检查不替代人工二次审核，也不要求补录空缺答案和解析。

## 1. 统一入口

本地 Codex 收到录题任务后，自动完成任务内全部题目的转写、题图/表格绑定、题型、知识板块、标签和校验，再交付待审核草稿。任务目录或“待转写”状态不属于完成交付。只有实际写入并核验过草稿，才能通知用户进行人工审核。

当前录入工作台的主要模式是：

- 批量试题录入：粘贴或导入多道 TeX，逐题生成草稿。
- 同卷试题录入：共享试卷来源，但每道题保留自己的题号和来源匹配结果。
- 同书试题录入：共享教材、页码和栏目等教材关系。
- PDF/图片识别：作为草稿生成能力接入录入流程，不直接入库。

## 2. 标准流程

```text
用户输入 TeX / 图片 / PDF
    ↓
来源元数据识别与人工确认
    ↓
云端 MinerU 版面解析（可选）或 PyMuPDF 回退
    ↓
按页、题号、坐标形成题目候选
    ↓
页面级 AI 输出题干、choices、答案、解析和分类草稿
    ↓
本地图片裁剪、图片绑定和 questionasset 草稿
    ↓
完全相同 / 高度相似 / 来源位置冲突检查
    ↓
人工逐题校订与二次审核
    ↓
正式题库写入、来源关系、图片关系、修订记录和导入记录
```

## 3. 来源处理

- 先确认年份、来源类型、卷别代码和试卷/教材/专题名称。
- AI 没识别到来源时，使用“未标记来源”，不要伪造年份或试卷名。
- 人工补充试卷名称后，再依据年份、卷别、文理/赛道和名称做模糊匹配。
- 同一批题如果每题识别出的来源不同，按题分组确认；没有可靠来源时不要强行继承错误的共同来源。

## 4. 草稿与审核

- `needs_review` 表示需要人工核对，不表示可以直接入库。
- `ready` 表示字段初检通过，仍需要人工最终确认。
- `approved` 绑定当前内容哈希，内容修改后必须撤销旧批准。
- `rejected` 或 `skip` 要保留理由和审核事件，保证后续可追溯。
- 原材料没有答案或解析时允许对应字段为空，所有年份均适用；不得因此要求补录或自行解题。缺题干、来源位置冲突或资源无法解析需要重点核对。

## 5. AI 边界

- PDF 识别的 AI 调用以页面或题目裁剪块为单位，不把整份 PDF 反复发送给模型。
- 大批量任务必须可查看进度、暂停、恢复、失败重试和最近任务状态。
- PDF 任务摘要必须保留输入文件哈希、解析器、模型、提示词指纹和识别器版本；逐题草稿还要保留实际识别 provenance，便于复现和追查。

## 6. 存储、版本控制与并行任务

- 草稿正文及审核状态在本地 SQLite，稳定草稿图在 `data/draft_assets/`，来源 PDF 在 `data/source_pdfs/`，原页、截图及识别载荷在 `data/imports/`。默认路径已被 Git 忽略，仍需本地备份。
- 强基、教材等并行任务使用独立子目录、批次及输出文件，不共享草稿输出文件，也不自行预分配正式题号；正式提交协调执行。
- 默认数据包不包含完整 `data/imports/`，需要时显式使用 `--include-ingestion`。`.ingestion/` 和工作区外来源需另外保留；新建任务不能默认假设任意目录均已被忽略。
- 当前检查结论及未验证边界见 [local-data-boundaries-and-status.md](local-data-boundaries-and-status.md)。
