# 录入审核预览格式补充规范

2026-10-26 补充，适用于后续真题录入和预览。

- 选择题作答空位 `（\hspace{1cm}）` 后不添加中文或英文句号。其他正文标点保留。新导入和视觉转写构建统一执行此规则。
- 选项按照实际渲染内容与当前题卡宽度优先排成四列，其次两列，最后单列。保持 A、B、C、D 的阅读顺序，长文字和图片选项也适用，缩放后重新计算。
- 图片 iframe 按图片及标题的实际高度自适应，不预留固定大块空白。图片下方仅显示标题，不重复拼接资源别名，也不显示“点击图片查看大图”。点击图片仍可放大。
- 前端公式采用 `\displaystyle` 的显示样式，分式以较大字号显示，保持在原来的行内位置；不将此展示命令写回题干、选项或导出源文。
- 换行仍使用两个空格加实际换行，禁止在录入正文中使用 `\par`。答案和解析不要求补录。

本次标点迁移涉及 2865 道草稿与 288 个转写源模块。数据库和源文件均有备份；迁移清单保留逐题修改前后内容，见 `reports/import_choice_punctuation_normalization.json`。历史批次 payload 和源页核对记录保留原样，年度对账通过迁移清单核对数据库的新正文，避免改写历史验收哈希。

显示验收覆盖桌面、中等宽度、手机宽度下的短公式、长文字、图片选项、放大图操作和窗口缩放。见 `reports/preview_layout_checks.json`。正式题库内容由 `scripts/audit_choice_punctuation_migration.py` 与迁移前数据库逐题比对。
