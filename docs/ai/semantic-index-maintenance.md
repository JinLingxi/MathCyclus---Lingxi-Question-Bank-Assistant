# 相似题语义索引维护

相似题页面读取 SQLite 正式题库。向量维护入口也读取同一正式题库，包含通过草稿审核后录入的教材、试卷及竞赛题；待审核草稿不进入正式索引。

向量以 sqlite://正式题目ID 标识，不要求题目存在独立 TeX 文件。题干、选项、标签、题型和知识板块决定内容指纹；只改文件路径、答案或解析无需重新生成题干向量。匹配时忽略内容指纹已失效的向量，仍可使用本地相似度规则。

在“工具箱 → 相似题查找 → 更新语义索引”中查看当前模型覆盖数和待更新数。进入维护页时从正式库重新对账并登记新增、变更项，无需依赖录入任务单独触发事件。索引数据库及待更新队列均为可重建派生数据，不向正式数据库写入索引状态。

普通更新仅生成当前模型缺失或内容变化的向量，每批落盘；接口失败后再次普通更新会跳过已完成的题目。完整一轮成功后才清理已不在当前题库中的旧索引条目。分批更新期间暂时包含多个模型时，相似题查找回退本地规则。

命令行检查（不发送 API 请求）：

    python -X utf8 scripts/update_sqlite_semantic_index.py

执行更新（调用 .env 中配置的向量服务，产生该服务的用量）：

    python -X utf8 scripts/update_sqlite_semantic_index.py --apply

执行器先建立旧索引的 SQLite 一致性备份，再发送请求；结果写入 reports/sqlite_semantic_update_时间.json。不在报告中保存 API 密钥或完整服务错误响应。更新期间若继续录题，执行结束后会再次读取正式库并登记新出现的待更新项。

AI_BASE_URL、AI_API_KEY 和 AI_EMBEDDING_MODEL_NAME 必须对应可用的 embeddings 服务。不要将完成代码改动、登记待更新队列或测试通过，视为全部真实向量已生成；最终以覆盖数和更新回执为准。

## 两种相似题查找模式

“同类题推荐”沿用综合评分权重：文本结构 45%、语义向量 30%、公式特征 10%、文字片段 8%、知识板块 4%、题型 3%。

“同题／变式核对”先按同题、高度相似、其他候选分组，再按文本结构分数排序，综合分用于进一步排序。该模式权重为文本结构 65%、向量 10%、公式特征 12%、文字片段 8%、知识板块 3%、题型 2%。这是一轮按检索用途区分的策略，尚未用人工标注样本校准，不应将相关度理解为数学等价概率。

关系判定仍使用已有本地规则和 0.60 主阈值，向量高分不能单独建立题目关系。两种模式均需人工勾选和保存才能登记关系，不会自动修改题目。

检索会补充正式题型 ID、全部关联知识板块和非答案/解析角色资源的数量，用于本地比较与提示。这些附加字段不会改变既有向量指纹。配图内容未比较时，题文一致也仅作为待核对相似候选，不标为已核实同题。

结果显示数字、关系符号、条件、区间、选项及题型差异；在“查看比较依据”中显示各分项分数、可用权重和未参与项目。切换检索模式或筛选条件后需要重新查找，不复用旧条件下的结果。

## 公式结构比较与评测

常见公式增加语法树比较：保留运算顺序、括号结构、分母、指数及下标位置。具体表达式通道保留数字和变量；结构通道可归一化参数和变量名，但保留变量重复使用模式及指数中的数值。推荐模式的公式分由 30% 具体表达式特征和 70% 结构特征构成，核对模式为 75% 和 25%。这仅替换原有公式分项的内部计算，综合权重和关系阈值未修改。

区间边界、常见函数的上标和对数底数、数学字体及向量标记分别保留；不会将向量符号与标量、不同集合运算或不同开闭区间归为相同表达式。结构通道只归一化当前表达式中的变量名，不将反复出现的同一变量与多个独立变量混为一谈。

算法不化简表达式，不证明数学等价，也不推断定义域相同。支持范围以测试为准；求和、积分、部分根式及格式不完整的表达式会回退基础符号比较，并显示解析未完成。区间和自然语言条件继续由现有差异规则提示。解析有大小和深度限制，避免异常公式阻塞检索。

离线回归检查：

    python -X utf8 scripts/evaluate_similarity.py

生成 120 组真实题对的待人工审核清单：

    python -X utf8 scripts/evaluate_similarity.py --prepare-review

工具生成 JSON、CSV 和 Markdown。题干、选项为只读快照；存在配图时还需在题库按 ID 查看图片。抽样来源包含已有来源关系、公式结构相近、同板块及全库对照；任何抽样类别都不会自动成为数学标签。

在 review.json 填写 human_label、reviewer、review_note 并将 review_status 置为 confirmed 后评测：

    python -X utf8 scripts/evaluate_similarity.py --review-file reports/相应文件.review.json

标签为 exact（同题）、variant（变式）、related（相关练习）、unrelated（无关）、uncertain（待定）。待审核、待定和无审核人记录不进入校准统计。只有同一基准题至少三组已确认候选且类别有差异时，才计算该组的推荐 nDCG@10；报告同时给出各类分数分布。

200 组开发者构造的公式回归用例验证语法处理，不是人工标注题库，也不能代表真实检索准确率。工具不会自动调整权重、阈值或正式题目关系；当前真实题对尚待人工标注，整体检索质量结论暂缺。
