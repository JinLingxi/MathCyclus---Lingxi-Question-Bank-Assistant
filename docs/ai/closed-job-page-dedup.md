# 已结束 PDF 任务的重复页面整理

2026-11-08 用户授权整理 `data/imports/pdf_jobs` 和 `data/imports/codex_2024_restart`，湘教版在录任务不纳入。待审核草稿及其来源、识别结果、裁剪图、任务清单、原 PDF、恢复归档均保留。

`scripts/deduplicate_closed_job_pages.py` 默认只做预演；加 `--apply` 执行。工具仅处理上述两个目录的 `pages/*.png`：有任务清单和原 PDF、超过一天未更新、当前无其他硬链接的页面。正式数据库草稿通过 `document_job_id` 引用的任务整组排除。大小相同后仍逐份计算 SHA-256，唯一页面不整理。

相同页面保留所有原路径，用 NTFS 硬链接共享同一份只读字节。数据库不写入，JSON 和 OCR 不改写，不删除或重建题目。目录属性中按每条路径累加的大小可能保持不变；实际减少的是重复文件的数据占用。已有共享的来源 PDF 不重复计算为新释放空间。

执行时锁定原文件与共享文件，核对字节，建立临时硬链接，验证后持久化凭据，使用 Windows `FileRenameInfoEx` 原子替换目录项，再次验证。占用、变化或不支持替换的文件保留；不会通过强制解除锁定来处理。共享页面设为只读以避免原地写入误改其他路径；需要手工编辑时应先复制为独立文件，不要直接去掉共享文件的只读属性再修改。清理不是删除全部旧任务资料。

计划、逐项凭据和结果在 `reports/closed_job_page_dedup_时间戳.*`。归档目录 `data/backups/cold_archives` 仍保留前两轮恢复凭据，本轮不删除。

后续审核清单为 `reports/draft_review_tomorrow_20261108.json`。其中 31 条 `position_replacement` 草稿专门保全旧答案解析，不能因新题已入库而直接删除；其他待审核草稿需要逐题比对正式库后再决定。本轮不修改题干、选项、答案或解析。
