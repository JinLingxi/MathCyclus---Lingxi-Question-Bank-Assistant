## 追加：多来源关系规划与结构化选项编辑器

### 设计沉淀

本轮把三个长期方向写入 `题库数据库重构实施规划.md`：

- 多来源关系模型：
  - 同一道题可以同时关联高考卷、教材、模考卷和专题；
  - 题卡顶部只显示主来源摘要；
  - 复杂来源未来进入右侧 `题目资料` 抽屉；
  - 抽屉内分 `来源关系`、`图片资源`、`修订记录`。
- SQLite 源码与 TeX 导出格式分离：
  - SQLite 内部不再把 `Begin Label Data` 当作题目源码；
  - `Label Data` 只由旧格式导出器生成；
  - 未来前端区分 `结构化源码` 与 `兼容导出预览`。
- 结构化选项编辑器：
  - 用户只填选项内部 TeX；
  - 前端或导出器自动生成 `\choice{{...}}`；
  - 短期不迁移历史 `choices_json`，先做兼容层。

### 本轮实现

- `question_bank_app.py`
  - SQLite 单题编辑态中，原来的 `选项（每行一个）` 改为结构化选项编辑区；
  - 新增选项数量控件，支持 0～8 个选项；
  - 每个选项用 A/B/C/D... 标注；
  - 用户填写内部 TeX，例如 `$\dfrac{\pi}{4}$`；
  - 保存前自动转回当前兼容格式 `{...}`，继续复用原 `choices_text -> choices_json` 保存逻辑。
- `services/export_service.py`
  - 新增 `format_choice_item()`；
  - 兼容历史 `{...}` 选项；
  - 兼容未来纯内部 TeX 选项；
  - 两种输入最终都能导出为 `\choice{{...}}`。
- `scripts/smoke_source_export_service.py`
  - 增加 `choice_item_wraps_inner_tex`；
  - 增加 `choice_item_keeps_wrapped_tex`。
