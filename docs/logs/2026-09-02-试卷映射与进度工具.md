- 左侧栏下方新增 `AI 图片 / PDF 识别`；
- AI 识别结果会按当前模式回填：
  - 单题录入：自动填入年份、卷别、来源名称、题号、知识板块、题干、选项、答案、解析；
  - 批量/同卷/同书：自动追加到批量 TeX 输入区；
- 移除左侧 `草稿状态` 统计，避免录入时出现无关后台感；
- 单题录入中间列恢复接近旧 `单题详情` 的结构：
  - 年份 / 知识板块 / 试卷类别；
  - 试卷或来源名称 / 题号页码 / 小题开关；
  - 来源类型 / 文理新高考 / 题型 / 难度；
  - 标签 / 备注 / AI 自动打标签；
  - 题干、选项、答案、解析；
- `来源标签` 不再让用户手填，改为根据来源类型、年份、来源名称和题号自动生成；
- `入库动作`、`目标 question_id`、`官方题 / 官方来源` 不再出现在单题录入表单；
- 单题保存固定作为新增题草稿，正式 ID 后续由系统入库流程分配；
- 单题模式不再默认展开 `草稿审核与确认入库`，该区域只保留给批量、同卷、同书录入；
- 右侧预览移除 `下载当前草稿 TeX`，改为生成完整题图，并提供下载图片与浏览器允许时复制图片。
