\begin{problem}{2007}{G}{辽宁卷（理）}{12}{导数}
已知 $ f(x) $ 与 $ g(x) $ 是定义在 $ \mathbb{R} $ 上的连续可导函数，如果 $ f(x) $ 与 $ g(x) $ 仅当 $ x=0 $ 时的函数值为 $ 0 $，且 $ f(x)\geq g(x) $，那么下列情形不可能出现的是（ ） (\hspace{1cm})
\begin{choices}
\choice{{0 是 $ f(x) $ 的极大值，也是 $ g(x) $ 的极大值}}
\choice{{0 是 $ f(x) $ 的极小值，也是 $ g(x) $ 的极小值}}
\choice{{0 是 $ f(x) $ 的极大值，但不是 $ g(x) $ 的极值}}
\choice{{0 是 $ f(x) $ 的极小值，但不是 $ g(x) $ 的极值}}
\end{choices}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solutions}
$ ABD $ 选项均有可能出现．

对于选项 $ C $，当 $ 0 $ 是 $ f(x) $ 极大值时，那么必然存在 $ m,n $ 使得 $ f(x) $ 在 $ (m,0)\cup(0,n) $ 上恒负，进而 $ g(x) $ 在 $ (m,0)\cup(0,n) $ 上恒负，结合 $ g(0)=0 $ 可知 $ 0 $ 一定是 $ g(x) $ 的极大值，选 $ C $．
\end{solutions}
