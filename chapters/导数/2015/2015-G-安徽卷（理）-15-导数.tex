\begin{problem}{2015}{G}{安徽卷（理）}{15}{导数}
设 $ x^3 + ax + b = 0 $，其中 $ a $，$ b $ 均为实数，下列条件中，使得该三次方程仅有一个实根的是\underline{\hspace{4em}}.（写出所有正确条件的编号）

\circled{1} $ a = -3 $，$ b = -3 $\qquad \circled{2} $ a = -3 $，$ b = 2 $\qquad \circled{3} $ a = -3 $，$ b > 2 $

\circled{4} $ a = 0 $，$ b = 2 $\qquad \circled{5} $ a = 1 $，$ b = 2 $
\end{problem}

\begin{answer}
\circled{1}\circled{3}\circled{4}\circled{5}
\end{answer}

\begin{solutions}
令 $ f(x) = x^3 + ax + b $，求得导数 $ f'(x) = 3x^2 + a $.

当 $ a \geq 0 $ 时，$ f'(x) \geq 0 $，所以 $ f(x) $ 单调递增，且至少存在一个数使 $ f(x) < 0 $，至少存在一个数使 $ f(x) > 0 $，所以 $ f(x) = x^3 + ax + b $ 必有一个零点，即方程 $ x^3 + ax + b = 0 $ 仅有一根，故\circled{4}\circled{5}正确；

当 $ a < 0 $ 时，若 $ a = -3 $，则 $ f'(x) = 3x^2 - 3 = 3(x+1)(x-1) $，易知，$ f(x) $ 在 $ (-\infty, -1) $，$ (1, +\infty) $ 上单调递增，在 $ [-1, 1] $ 上单调递减，

所以 $ f(x)_{\text{极大}} = f(-1) = -1 + 3 + b = b + 2 $，$ f(x)_{\text{极小}} = f(1) = 1 - 3 + b = b - 2 $，

要使方程仅有一根，则 $ f(x)_{\text{极大}} = f(-1) = -1 + 3 + b = b + 2 < 0 $ 或者 $ f(x)_{\text{极小}} = f(1) = 1 - 3 + b = b - 2 > 0 $，

解得 $ b < -2 $ 或 $ b > 2 $，故\circled{1}\circled{3}正确。

所以使得三次方程仅有一个实根的是\circled{1}\circled{3}\circled{4}\circled{5}.
\end{solutions}
