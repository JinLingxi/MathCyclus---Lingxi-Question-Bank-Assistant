\begin{problem}{2016}{G}{浙江卷}{5}{三角函数}
设函数 $ f(x)=\sin^2x+b\sin x+c $，则 $ f(x) $ 的最小正周期 (\hspace{1cm})
\begin{choices}
\choice{{与 $ b $ 有关，且与 $ c $ 有关}}
\choice{{与 $ b $ 有关，但与 $ c $ 无关}}
\choice{{与 $ b $ 无关，且与 $ c $ 无关}}
\choice{{与 $ b $ 无关，但与 $ c $ 有关}}
\end{choices}
\end{problem}

\begin{answer}
B
\end{answer}

\begin{solutions}
$ f(x)=-\dfrac{\cos 2x}{2}+b\sin x+c+\dfrac{1}{2} $.  

当 $ b=0 $ 时，$ f(x) $ 的最小正周期是 $ \pi $；当 $ b\neq 0 $ 时，$ f(x) $ 的最小正周期是 $ 2\pi $.  

另外，$ c $ 的改变只会让 $ y=f(x) $ 的图像上下平移，不会改变最小正周期.  

因此 $ f(x) $ 的最小正周期与 $ b $ 有关，但与 $ c $ 无关.
\end{solutions}
