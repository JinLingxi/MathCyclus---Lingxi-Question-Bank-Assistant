\begin{problem}{2010}{G}{江苏卷}{13}{三角函数}
在锐角 $ \triangle ABC $ 中，角 $ A $、$ B $、$ C $ 的对边分别为 $ a $、$ b $、$ c $，若 $ \dfrac{a}{b} + \dfrac{b}{a} = 6 \cos C $，则 $ \dfrac{\tan C}{\tan A} + \dfrac{\tan C}{\tan B} $ 的值是 \underline{\hspace{4em}}.
\end{problem}

\begin{answer}
$ 4 $
\end{answer}

\begin{solutions}
因为 $\dfrac{a}{b} + \dfrac{b}{a} = 6 \cos C $,  
由余弦定理可得 $ \dfrac{a^2 + b^2}{ab} = 6 \cdot \dfrac{a^2 + b^2 - c^2}{2ab} $,  
所以 $ a^2 + b^2 = \dfrac{3c^2}{2} $.  

则 $ \dfrac{\tan C}{\tan A} + \dfrac{\tan C}{\tan B} = \dfrac{\cos A \sin C}{\cos C \sin A} + \dfrac{\cos B \sin C}{\cos C \sin B} = \dfrac{\sin C}{\cos C} \left( \dfrac{\cos A}{\sin A} + \dfrac{\cos B}{\sin B} \right) $  
$ = \dfrac{\sin C}{\cos C} \cdot \dfrac{\cos A \sin B + \cos B \sin A}{\sin A \sin B} = \dfrac{\sin C}{\cos C} \cdot \dfrac{\sin (A + B)}{\sin A \sin B} = \dfrac{\sin C \cdot \sin C}{\cos C \cdot \sin A \sin B} = \dfrac{\sin^2 C}{\sin A \sin B \cos C} =\dfrac{c^2}{ab \cos C }$.  

$ =\dfrac{c^2}{ab} \cdot \dfrac{2ab}{a^2 + b^2 - c^2} = \dfrac{2c^2}{a^2 + b^2 - c^2} = \dfrac{2c^2}{\dfrac{3c^2}{2} - c^2} = \dfrac{2c^2}{\dfrac{c^2}{2}} = 4 $.
\end{solutions}
