\begin{problem}{2018}{G}{全国I卷（理）}{2}{集合}
已知集合 $ A = \{x \mid x^2 - x - 2 > 0\} $，则 $ \complement_{\mathbb{R}} A = $ (\hspace{1cm})
\begin{choices}
\choice{{$\{x \mid -1 < x < 2\}$}}
\choice{{$\{x \mid -1 \leqslant x \leqslant 2\}$}}
\choice{{$\{x \mid x < -1\} \cup \{x \mid x > 2\}$}}
\choice{{$\{x \mid x \leqslant -1\} \cup \{x \mid x \geqslant 2\}$}}
\end{choices}
\end{problem}

\begin{answer}
(B) $\{x \mid -1 \leqslant x \leqslant 2\}$
\end{answer}

\begin{solutions}
解不等式 $ x^2 - x - 2 > 0 $，即 $ (x - 2)(x + 1) > 0 $，得 $ x < -1 $ 或 $ x > 2 $，故 $ A = \{x \mid x < -1\} \cup \{x \mid x > 2\} $.  
因此 $ \complement_{\mathbb{R}} A = \{x \mid -1 \leqslant x \leqslant 2\} $.
\end{solutions}
