\begin{problem}{2012}{G}{福建卷（理）}{7}{函数}
设函数 $D(x) = \begin{cases} 1, & x \text{ 为有理数} \\ 0, & x\text{ 为无理数} \end{cases} $，则下列结论错误的是
\begin{choices}
\choice{{$D(x)$ 的值域为 $\{0,1\}$}}
\choice{{$D(x)$ 是偶函数}}
\choice{{$D(x)$ 不是周期函数}}
\choice{{$D(x)$ 不是单调函数}}
\end{choices}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solutions}
(A) 正确，函数只取 0 和 1；  
(B) 正确，因有理数的相反数仍为有理数，无理数的相反数仍为无理数，故 $ D(-x) = D(x) $；  
(C) 错误，事实上 $ D(x) $ 是周期函数，任意非零有理数 $ r $ 都是其周期，因为若 $ x $ 为有理数，则 $ x + r $ 为有理数；若 $ x $ 为无理数，则 $ x + r $ 为无理数，故 $ D(x + r) = D(x) $；  
(D) 正确，因在任意区间内既有有理数也有无理数，函数值在 0 和 1 间跳跃，故不单调。
\end{solutions}
