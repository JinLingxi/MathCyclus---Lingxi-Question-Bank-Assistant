\begin{problem}{2005}{G}{全国II卷}{5}{复数}
设 $ a $、$ b $、$ c $、$ d \in \mathbb{R} $，若 $ \dfrac{a+bi}{c+di} $ 为实数，则 (\hspace{1cm})
\begin{choices}
\choice{{ $ bc+ad \ne 0 $ }}
\choice{{ $ bc-ad \ne 0 $ }}
\choice{{ $ bc-ad = 0 $ }}
\choice{{ $ bc+ad = 0 $ }}
\end{choices}
\end{problem}

\begin{answer}
C
\end{answer}

\begin{solutions}
将复数 $ \dfrac{a+bi}{c+di} $ 的分子、分母同乘分母的共轭复数，得
$$
\dfrac{a+bi}{c+di} = \dfrac{(a+bi)(c-di)}{c^2+d^2}.
$$
因为分母是实数，所以当分子的虚部 $ bc-ad = 0 $ 时，$ \dfrac{a+bi}{c+di} $ 为实数，故选 C.
\end{solutions}
