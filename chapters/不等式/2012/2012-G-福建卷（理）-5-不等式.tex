\begin{problem}{2012}{G}{福建卷（理）}{5}{不等式}
下列不等式一定成立的是
\begin{choices}
\choice{{$\lg\left(x^2 + \dfrac{1}{4}\right) > \lg x \ (x > 0)$}}
\choice{{$\sin x + \dfrac{1}{\sin x} \geqslant 2 \ (x \ne k\pi,\ k \in \mathbb{Z})$}}
\choice{{$x^2 + 1 \geqslant 2|x| \ (x \in \mathbb{R})$}}
\choice{{$\dfrac{1}{x^2 + 1} > 1 \ (x \in \mathbb{R})$}}
\end{choices}
\end{problem}

\begin{answer}
(C)
\end{answer}

\begin{solutions}
(A) 错误，当 $ x = \dfrac{1}{2} $ 时，$ x^2 + \dfrac{1}{4} = \dfrac{1}{2} = x $，故 $ \lg\left(x^2 + \dfrac{1}{4}\right) = \lg x $；  
(B) 错误，当 $ \sin x < 0 $ 时，$ \sin x + \dfrac{1}{\sin x} \leqslant -2 $；  
(C) 正确，由 $ (|x| - 1)^2 \geqslant 0 $ 得 $ x^2 - 2|x| + 1 \geqslant 0 $，即 $ x^2 + 1 \geqslant 2|x| $；  
(D) 错误，因 $ x^2 + 1 \geqslant 1 $，故 $ \dfrac{1}{x^2 + 1} \leqslant 1 $，仅当 $ x = 0 $ 时取等号。
\end{solutions}
