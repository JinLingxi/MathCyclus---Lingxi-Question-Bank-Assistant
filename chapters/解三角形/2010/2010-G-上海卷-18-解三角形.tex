\begin{problem}{2010}{G}{上海卷}{18}{解三角形}
某人要制作一个三角形，要求它的三条高的长度分别是 $ \dfrac{1}{13} $，$ \dfrac{1}{11} $，$ \dfrac{1}{5} $，则此人将 (\hspace{1cm})
\begin{choices}
\choice{{不能作出满足要求的三角形}}
\choice{{作出一个锐角三角形}}
\choice{{作出一个直角三角形}}
\choice{{作出一个钝角三角形}}
\end{choices}
\end{problem}

\begin{answer}
D
\end{answer}

\begin{solutions}
因为 $ \dfrac{a}{\sin A} = \dfrac{b}{\sin B} = \dfrac{c}{\sin C} = 2R $，所以 $ \sin A = \dfrac{a}{2R} $，$ \sin B = \dfrac{b}{2R} $，$ \sin C = \dfrac{c}{2R} $，

由题意 $ a \cdot \sin A = \dfrac{1}{5} $，$ b \cdot \sin B = \dfrac{1}{11} $，$ c \cdot \sin C = \dfrac{1}{13} $，

则 $ \dfrac{a^2}{2R} = \dfrac{1}{5} $，$ \dfrac{b^2}{2R} = \dfrac{1}{11} $，$ \dfrac{c^2}{2R} = \dfrac{1}{13} $，

$ \cos \theta = \dfrac{ \dfrac{1}{11} + \dfrac{1}{13} - \dfrac{1}{5} }{ 2 \sqrt{ \dfrac{1}{11} \cdot \dfrac{1}{13} } } < 0 $，所以，一定是钝角三角形.
\end{solutions}
